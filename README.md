## Concepts learned

### Introduction & Variables

Topics: Learned how to compile a C program, Hello World program, comments in C programs, variables and their naming conventions, basic output functions, variable scope, and basic input/output.

### Fundamental Data Types

Topics: Learned integer data types, character (`char`) data type, floating-point data types (`float` and `double`), `sizeof` operator, integer modifiers, and what happens when values exceed valid ranges.

### Constants

Topics: Learned how to define and use constants in C and the difference between variables and constants.

### Operators

Topics: Learned arithmetic operators, relational operators, increment and decrement operators, and basic comparison and logical operations.

### Arrays

Topics: Learned the basics of arrays, storing multiple values of the same data type, taking array input, traversing arrays, and performing basic operations on array elements.
